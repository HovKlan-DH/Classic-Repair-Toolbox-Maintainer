# CRT Maintainer

This repository holds only the **releases** of **CRT Maintainer**: the tool used by the maintainers of _Classic Repair Toolbox_ (CRT) boards to review and publish the contributions the community submit.

It is of no use without a maintainer account. If you are looking for the **Classic Repair Toolbox** application itself, it is here: https://github.com/HovKlan-DH/Classic-Repair-Toolbox

## Download

[Latest release](https://github.com/HovKlan-DH/Classic-Repair-Toolbox-Maintainer/releases/latest) - the Windows installer (`...-Setup.exe`) and the Linux `.AppImage`.
