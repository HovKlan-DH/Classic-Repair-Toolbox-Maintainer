# CRT Maintainer

This repository holds only the **releases** of **CRT Maintainer**: the tool used by the maintainers of Classic Repair Toolbox boards to review the contributions people submit, and to publish the ones that are right.

It is of no use without a maintainer account. If you are looking for **Classic Repair Toolbox** itself, it is here: https://github.com/HovKlan-DH/Classic-Repair-Toolbox

## Download

[Latest release](https://github.com/HovKlan-DH/Classic-Repair-Toolbox-Maintainer/releases/latest) - the Windows installer (`...-Setup.exe`) and the Linux `.AppImage`.

## Source code and questions

Everything else - source code, issues and discussion - is in the main repository: https://github.com/HovKlan-DH/Classic-Repair-Toolbox

The releases here are built and published automatically from that repository; nothing else is kept here.
