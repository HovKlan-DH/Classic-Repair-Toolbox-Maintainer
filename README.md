# Classic Repair Toolbox - Review application

This repository holds only the **releases** of the Classic Repair Toolbox review application: the tool used by the people who review contributions, to check submitted board data and publish it.

It is of no use without a review account. If you are looking for **Classic Repair Toolbox** itself, it is here: https://github.com/HovKlan-DH/Classic-Repair-Toolbox

## Download

[Latest release](https://github.com/HovKlan-DH/Classic-Repair-Toolbox-Review/releases/latest) - the Windows installer (`...-Setup.exe`) and the Linux `.AppImage`.

## Source code and questions

Everything else - source code, issues and discussion - is in the main repository: https://github.com/HovKlan-DH/Classic-Repair-Toolbox

The releases here are built and published automatically from that repository; nothing else is kept here.
